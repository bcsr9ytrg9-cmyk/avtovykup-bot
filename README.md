# АвтоВыкуп — Telegram-бот для приёма заявок

## Возможности

### Клиент
- кнопка «Оставить заявку»;
- имя;
- номер телефона;
- марка и модель;
- год;
- пробег;
- город;
- состояние;
- информация о ДТП;
- желаемая цена;
- несколько фотографий;
- подтверждение отправки.

### Владелец бизнеса
Каждая новая заявка приходит в Telegram владельцу бота:

- номер заявки;
- контакты клиента;
- характеристики автомобиля;
- желаемая цена;
- фотографии;
- кнопка «В работу»;
- кнопка «Отказ»;
- кнопка «Предложить цену».

Все заявки сохраняются в SQLite.

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

Создайте бота через @BotFather и получите токен.

Нужно узнать свой Telegram ID. Это можно сделать через любого бота, который показывает Telegram user ID.

### Windows PowerShell

```powershell
$env:BOT_TOKEN="ТОКЕН_БОТА"
$env:ADMIN_ID="ВАШ_TELEGRAM_ID"
python bot.py
```

### macOS/Linux

```bash
export BOT_TOKEN="ТОКЕН_БОТА"
export ADMIN_ID="ВАШ_TELEGRAM_ID"
python3 bot.py
```

После запуска откройте своего бота и нажмите Start.

## Важный момент

Не публикуйте BOT_TOKEN и не передавайте его другим людям.
